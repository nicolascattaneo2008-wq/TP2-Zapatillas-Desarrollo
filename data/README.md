# Datos del inventario

## Origen
Los datos son simulados y fueron preparados para este trabajo práctico. No representan el inventario de una tienda real.

No se utilizaron bases de datos externas ni información personal.

## Archivos

El proyecto contiene dos archivos de datos:

- zapatillas.csv
- zapatillas.json

Ambos contienen los mismos 60 productos y las mismas 6 variables.

Los datos son simulados y se utilizarán para comprobar que el programa puede leer los dos formatos.
zapatillas.csv contiene 60 registros y 6 variables.

Cada fila representa un modelo de zapatilla en un talle determinado.

## Variables
- codigo: identificador único del producto.
- marca: marca de la zapatilla.
- modelo: nombre del modelo.
- talle: talle de la zapatilla.
- stock: cantidad de pares disponibles.
- stock_minimo: cantidad mínima que se desea mantener.

## Preparación de los datos
Se prepararon 60 registros ficticios con diferentes marcas, modelos, talles y cantidades de stock.

Los códigos van de ZAP-001 a ZAP-060.

## Limitaciones
Los datos son simulados y no representan ventas ni existencias reales. Se utilizan para demostrar el funcionamiento del sistema.
